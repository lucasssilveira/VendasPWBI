# 📊 Dashboard de Vendas

![Dashboard de Vendas](dashboard_vendas.png)

## 📌 Sobre o Projeto

Este projeto apresenta um **Dashboard de Vendas desenvolvido no Power
BI**, com o objetivo de transformar dados de vendas em informações
visuais que auxiliem na análise do desempenho comercial.

O dashboard permite visualizar indicadores de faturamento, quantidade de
produtos vendidos, lucro e quantidade de clientes, além de possibilitar
a análise das vendas ao longo do tempo, por marca e por continente.

## 🎯 Objetivos

-   Acompanhar o faturamento total das vendas;
-   Analisar a quantidade de produtos vendidos;
-   Avaliar o lucro total;
-   Identificar a quantidade de clientes;
-   Acompanhar a evolução do faturamento por ano e mês;
-   Comparar o faturamento entre diferentes marcas;
-   Analisar a distribuição das vendas por continente;
-   Facilitar a identificação de tendências e oportunidades comerciais.

## 📊 Visualizações

### Faturamento por Ano e Mês

Gráfico de linha utilizado para acompanhar a evolução do faturamento ao
longo do período analisado, permitindo identificar períodos de maior e
menor desempenho.

### Faturamento por Marca

Gráfico de barras utilizado para comparar o faturamento das principais
marcas. Entre os destaques apresentados estão:

-   Contoso
-   Litware
-   Proseware
-   Southridge Video
-   Hashtag Toys
-   Wide World Importers
-   Northwind Traders

### Faturamento por Continente

Mapa utilizado para apresentar a distribuição geográfica do faturamento,
permitindo uma visão geral do desempenho das vendas em diferentes
regiões do mundo.

## 🛠️ Ferramentas Utilizadas

-   **Microsoft Power BI**
-   **Power Query** para tratamento e transformação dos dados
-   **DAX** para criação de medidas e indicadores
-   **Visualizações interativas** para análise dos dados

## 🔎 Análises Possíveis

Com o dashboard é possível responder perguntas como:

-   Qual é o faturamento total?
-   Qual foi o lucro obtido?
-   Como o faturamento evoluiu ao longo dos meses?
-   Quais marcas apresentam maior faturamento?
-   Como as vendas estão distribuídas geograficamente?
-   Quais períodos apresentam maior ou menor desempenho?

## 💡 Insights

O dashboard demonstra como a utilização de ferramentas de Business
Intelligence pode transformar dados brutos em informações mais claras e
úteis para a tomada de decisão.

A combinação de **indicadores, gráficos temporais, ranking de marcas e
análise geográfica** proporciona uma visão geral do desempenho comercial
e facilita a identificação de padrões.
